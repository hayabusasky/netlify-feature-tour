## 2. トレンド・キーワード

### 2-1. 副業市場（会社員）
- 【事実】20〜40代会社員の直近半年の副業実施率は **46.7%**。2026年5月調査（39.3%）から+7.4pt。今後半年の副業意向は53.9%。調査はロッツフル（lotsful）、2026年8月実施。対象は正社員に限らない
  - 出典: [マイナビニュース](https://news.mynavi.jp/article/20260930-5048668/) / [ビジネス+IT](https://www.sbbit.jp/article/cont1/187146)
- 【事実】同じ調査の副業月収: 5万円未満 20.9% / 5〜10万円 21.6% / 10〜20万円 22.6% / 30万円以上 19.3%。副業の理由1位は「自由に使えるお金を増やしたい」35.8%
  - 出典: 同上
  - 注意【推測】: この調査の対象は副業プロ人材サービスの利用者層に近い可能性があり、一般の会社員より高めに出ているかもしれない。別の分析では、副業収入の中央値は月1〜3万円とされている（[ゼロスタ](https://note.com/zero_sta1/n/naf3fce67a8ea)。note記事のため本文は未確認）
- 【事実】パーソル総合研究所の「第四回 副業の実態・意識に関する定量調査」（2025年10月発表）では、副業実施率と企業の副業容認率がともに過去最高
  - 出典: [パーソル総合研究所](https://rc.persol-group.co.jp/news/release-20251028-1000-1/)
- 【事実（二次情報）】経団連の調査（2026年3月）で、主要企業の83.9%が副業を容認または容認予定と紹介されている
  - 出典: [tmo-blog](https://tmo-blog.com/%E3%80%902026%E5%B9%B4%E6%9C%80%E6%96%B0%E3%80%91%E3%82%B9%E3%82%AD%E3%83%9E%E3%83%90%E3%82%A4%E3%83%88%EF%BC%88%E3%82%BF%E3%82%A4%E3%83%9F%E3%83%BC%EF%BC%89%E5%89%AF%E6%A5%AD%E3%81%AE%E5%A7%8B/)（個人ブログ。経団連の原典は未確認）

- 【事実】副業の所得が20万円以下なら所得税の確定申告は不要だが、住民税の申告は必要。会社に知られたくない場合は、確定申告書の住民税欄で「普通徴収」を選ぶ方法が一般的に紹介されている
  - 出典: [弥生](https://www.yayoi-kk.co.jp/shinkoku/oyakudachi/fukugyo-barenai/) / [マネーフォワード](https://biz.moneyforward.com/tax_return/basic/55747/)
- 【事実（複数の二次情報）】「106万円の壁」（社会保険の月額賃金8.8万円の要件）は2026年10月に撤廃とする報道・解説が多い。撤廃後は「週20時間以上」が基準。企業規模の要件は2027年10月から段階的に縮小
  - 出典: [Yahoo!ニュース（共同通信）](https://news.yahoo.co.jp/articles/b9a1067cab67255ca89fa3a339f9121156ccf2ef) / [社会保険研究所](https://media.shaho.co.jp/n/naa539eedd95c?gs=bd66f49e67acf87f8bc156caf7dbf268)
  - **要確認**: 法律上の施行日は「公布から3年以内に政令で定める」で、最低賃金の条件付きとする解説もある（[オフィスステーション](https://romsearch.officestation.jp/news/49052)）。投稿の前に厚生労働省の一次情報で施行日を確認すること
- 【事実（二次情報）】所得税がかかり始める年収は2025年分で160万円、2026年分で178万円に引き上げと解説されている
  - 出典: [弥生](https://www.yayoi-kk.co.jp/kyuyo/oyakudachi/nenshu-kabe/) / [taxlabor](https://taxlabor.com/nenshu-kabe-2026-178man/)

### 3-2. アルゴリズム（Metaの公式発表と、海外記事の未検証の主張を分ける）
- 【事実】Meta は、Threadsのフィード表示にAIのランキングを使っていると説明している（[Vista Social](https://vistasocial.com/insights/threads-algorithm) などの海外解説記事による要約）
- 【未検証（海外の解説記事の主張）】「いいねより返信の重みが大きい」「最初の反応が付く速さ（初速）が重要」「リポストの重みが大きい」「フォロワーとの会話が広がる『Connected Reach』重視」
  - 出典: [Vista Social](https://vistasocial.com/insights/threads-algorithm) / [Bulk Publish（確定と未確定を分けて整理）](https://www.bulkpublish.com/blog/threads-algorithm/) / [getautodm](https://getautodm.com/en/guides/threads-algorithm-2026/)
  - 【推測】Metaが「返信文化」を公に強調しているので、**返信を誘う投稿**を基本にするのは理にかなっている。数値（返信は10倍など）は根拠が確認できないので使わない
- リンクの扱い: Xでは「外部リンクは減点」という説があるが、2026年9月時点の公開コードには減点の重みが見当たらないという検証もある（[Xの記事](https://x.com/cosplay_pixel/article/2056290684722926010) / [issoh](https://www.issoh.co.jp/tech/details/10690/)）。**Threadsのリンクの扱いは確認できる根拠が見つからなかった**。テストでは「本文にリンクなし、プロフィールと自己返信にnoteリンク」で統一し、比較の条件を揃える【推測にもとづく運用ルール】

### 3-3. 伸びている投稿の形式（二次情報＝note記事の要約。本文は未確認）
- 有益情報型は「100〜150字で3〜5行ごとに改行」か「500字以内」が基本とされる
  - 出典: [リンゴ（note）「Threadsで伸びる投稿テンプレ10選」](https://note.com/nice_heron4924/n/n24b864e157ea) / [アプリの達人](https://app-tatsujin.com/threads-character-limit-2026/)
- 「本文150〜200字でフック → 自己返信1で体験談400〜500字 → 自己返信2で応用とnoteへの誘導」の3段構成が紹介されている
  - 出典: 同上（検索要約）
- 「Threadsで共感を集め、noteで深く解決する」という役割分担が、再現性が高いとされている
  - 出典: [リンゴ（note）](https://note.com/nice_heron4924/n/n24b864e157ea) / [けと（note）「Threads→noteの導線設計5ステップ」](https://note.com/keto8152/n/n12d05d35b4c7) / [ひで（note）](https://note.com/tothinks/n/na7058f995306)
- 【推測】まとめると、Threadsで伸びやすいのは
  1. 冒頭1行が「状況の言い当て」か「数字」（例: 「平日30分しか取れない人へ」「3か月で〇円、時給にすると〇円」）
  2. 結論 → 理由 → 自分の体験の順で、短くまとめる
  3. 最後を問いかけで終わらせて、返信を集める（「あなたは何時に作業してますか？」）
  4. 長い話は添付テキストか自己返信に回し、本文は短くする

### 3-4. Threadsでこのジャンルを扱うときの注意（重要）
- 【事実】副業の投稿のコメント欄には「DMで教えます」型の勧誘が付きやすい（2-5の知恵袋の体験談）
- 【推測】放置すると、アカウント自体が「怪しい副業アカウント」に見えるおそれがある。運用ルールの案:
  - プロフィールに「DM・LINEへの勧誘はしていません」と書く
  - 勧誘コメントは非表示にする（Threadsの返信非表示・制限機能を使う）
  - 「誰でも」「簡単に」「スマホだけで」「必ず」は使わない（noteの規約・消費者庁の注意喚起とも一致する）

### 差別化の切り口（推測）
「noteで稼ぐ方法」とは戦わず、次の3つの軸を組み合わせる。
1. **時間の制約から設計する**: 「平日30分・週末2時間しか取れない人の副業」。挫折の理由（時間・疲労）に直接答える。稼いだ額より「続いた仕組み」を売る
2. **お金の手続きを実務で整理する**: 住民税・確定申告・年収の壁（2026年の制度変更）。検索需要があり、情報の鮮度で勝てる。正確性が命なので一次情報リンクは必須
3. **安全を前面に出す**: 「勧誘しない・高額講座を売らない」を明言し、詐欺の見分け方を無料で出す。ThreadsではDM勧誘が多いので、それ自体が信頼の差になる

## 8. 2週間テスト用の無料投稿ネタ（Threads向け・10件）

### テストのルール（案）
- 期間: 2週間で10投稿（平日1本＋週末に調整）。他の2ジャンルと**同じ時間帯・同じ曜日**に投稿して比べる
- 形式: 本文は150字前後（3〜5行で改行）。長い補足は自己返信か添付テキストへ。本文にリンクは入れない
- 記録する指標: 閲覧数、返信数、リポスト数、いいね数、フォロワー増加数、プロフィールのリンクのクリック数（取れる範囲で）
- 判定の目安【推測】: 返信とリポストを最重視（Metaが返信文化を強調しているため）。「閲覧1,000あたりの返信数」で3ジャンルを比べる
- 【 】は実体験の数字に置き換える。実体験がないものは使わない

| # | 軸 | トピックタグ | 狙い | 形式 |

| 1 | 時間 | 会社員の副業 | 時間の制約への共感と、返信の誘発 | 本文のみ＋問いかけ |
