# ジャンルテスト計画（AI活用 / 副業・在宅ワーク / 育児・教育）

- 作成日: 2026-10-05
- 目的: 3ジャンルを同じ条件で2週間発信し、反応が最も良いジャンルを1つ残して有料noteにつなげる
- 各ジャンルのリサーチ: `sns/research/2026-10-05_AI活用.md` / `2026-10-05_副業在宅ワーク.md` / `2026-10-05_育児教育.md`

## 条件をそろえる（公平に比べるため）

| 項目 | 設定 |
|---|---|
| アカウント | ジャンルごとに別アカウント（1アカウントに混ぜると、どのジャンルの反応か分からなくなる） |
| SNS | 3ジャンルとも Threads（2026-10-05 決定） |
| 期間 | 2週間（14日） |
| 投稿数 | 各アカウント 1日1投稿、計14投稿 |
| 投稿時間 | 3アカウントとも同じ時間帯（例: 7時台または21時台） |
| 形式 | 3アカウントとも同じ比率にする（例: テキストのみ7・画像付き7）。スレッド形式（連投）を使う場合も3アカウントで回数をそろえる |
| 広告・相互フォロー | 使わない（自然な反応だけで比べる） |
| note導線 | noteアカウントはテスト中は1つで足りる。ジャンルごとに無料記事を1本ずつ用意し、各Threadsアカウントのプロフィールには自分のジャンルの記事だけをリンクする。記事ごとの閲覧数がそのままジャンル別の流入になる。noteアカウントを分けるかは、残すジャンルが決まってから判断する |

## 記録する数字（`sns/metrics/` にCSVで保存）

投稿ごとに、投稿から48時間後の数値を記録する。

Threads のインサイトで確認できる項目を記録する。インサイトに出ない項目は空欄でよい。

- 閲覧数
- いいね・返信・再投稿・引用・シェア
- 保存（インサイトに出る場合）
- リンククリック（インサイトに出る場合。出ない場合は note 側のアクセス解析で、参照元が Threads の流入を記録）
- フォロワー数（毎日同じ時刻に記録）

## 判定の基準（14日後）

点数は次の順に重く見る。有料noteを買う人に近い行動ほど重くする。

1. **noteへの流入（リンククリック）** … 有料noteの販売に一番近い
2. **保存率**（保存 ÷ 閲覧数）… 「あとで読みたい」需要の強さ。取れない場合は返信率で代用
3. **フォロワー増加数** … 継続して届けられる読者の数
4. **エンゲージメント率**（いいね・返信・再投稿・引用 ÷ 閲覧数）

- 1位のジャンルを残す
- 1位と2位の差が小さい場合（主要指標の差が2割未満）は、2ジャンルでもう1週間延長して判定する
- 判定は sns-pdca-checker に `sns/metrics/` の数値を渡して行い、`sns/reports/` に保存する

## 担当の流れ

1. sns-researcher: ジャンルごとのリサーチ（実施中）
2. sns-writer: 各ジャンル14投稿分の投稿文と投稿カレンダー
3. 投稿（人が実施）と数値の記録
4. sns-pdca-checker: 1週目で中間チェック、2週目で最終判定
